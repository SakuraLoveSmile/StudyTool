# StudyTool 联网服务 0.1.13

将知识库原来的层级列表升级为可以移动、缩放和全屏查看的章节思维导图。已保存的章节资料直接适配，无需重新生成、重新 OCR 或重建向量索引。

- 用连线展示章节、主题和知识点之间的关系；拖动画布空白处移动，提供放大、缩小、100% 与适应画布。
- 支持全屏阅读、展开或收起分支、搜索并定位知识点。保留大纲模式，手机默认使用便于阅读的大纲，也可切换导图。
- 点击节点后就近查看概念、背诵短段和原文，选中节点明确高亮；同名节点仍可独立定位。
- 在实际关联的节点标记“真题已考”和“管理学关联”，详情区展示对应真题及关联依据，保留关联建议与已考证据的区别。
- 概念说明改为精确匹配，避免较短的概念名称覆盖具体知识点；来源变化或尚未核实的资料继续禁用原文入口。
- 全屏内可直接打开原文弹窗，支持键盘切换与 Esc 逐层关闭，并恢复到原来的操作位置。

## 更新

```bash
docker compose --env-file .env pull
docker compose --env-file .env up -d
```

版本镜像：`ghcr.io/sakuralovesmile/studytool:0.1.13`；发布验证通过后同步更新 `latest`。更新后刷新网页，在“知识库学习 → 思维导图”中使用。
