# StudyTool 联网服务 0.1.9

回忆卡生成改为教材驱动：选择教材，可再限定原文章节，程序自动匹配有可靠来源的已有知识点、安排回忆卡目录并拆分生成任务，无需先手建章节或逐个勾选知识点。

- 归属由教材的真实章节与原文引用确定，支持章下的节标题和跨章合并知识点；不会因为目录叫“管理学”就把会计学知识点混入。
- 提交前显示可生成知识点、章节、任务数量及不可用原因。超过 20 个知识点自动分批；单知识点原文超限会明确提示，不截取来源或静默省略。
- 额外提示现在会进入不可变任务快照和模型输入。生成任务可从弹窗直接打开任务列表查看进度与阶段日志，结果仍为待审核候选。
- 预览不调用模型、不创建目录；提交时重新核验来源并原子创建批次。相同请求重试不会重复入队；生成期间原文或目标目录发生不兼容变化时停止写入。
- 保留已有手工目录、卡片和审核流程，不迁移数据或修改数据库结构。没有可靠引用的知识点仍需先在“考点分析”提取并审核，不能凭标题猜测教材归属。

## 验证

84 项后端检查与前端构建通过。本地隔离数据库和模拟模型验证了教材/章节匹配、自动分批、重复提交、来源及目录变化阻断、租户隔离与额外提示传递。真实网页验证了整书自动分章、章范围切换、科目隔离、无可用知识点引导、任务阶段日志和待审核卡片，并检查了 390×844 手机视口的预览及提交。未调用真实付费模型或 OCR，未修改生产服务器。

## 更新

```bash
docker compose --env-file .env pull
docker compose --env-file .env up -d
```

版本镜像：`ghcr.io/sakuralovesmile/studytool:0.1.9`；发布验证通过后同步更新 `latest`。更新并刷新网页，进入“回忆卡库 → 批量生成回忆卡”，选择教材或章节即可预览，再手动开始生成。开始生成会使用已配置模型的额度。
