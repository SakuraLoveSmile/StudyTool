# 联网版服务端 0.1.1

章节学习资料生成现在提交到后台任务队列，网页立即返回任务编号。离开或刷新页面后，可继续查看同一章节任务，完成后自动读取已保存资料。

任务详情提供读取来源、调用模型、响应校验、保存结果及重试日志。失败任务显示安全的具体原因，例如 ReadTimeout 或 HTTP 状态码；完成、失败和取消后仍可展开日志。点击旧章节任务时，即使它不在全局最近 50 条记录内，也能定位详情。

请求参数、来源快照与幂等键持久保存；重试使用原请求参数，来源变化时要求重新生成。取消与结果保存采用事务检查，取消后不会产生成功资料。原同步 API 保留兼容。

新版 Compose 默认 LLM_TIMEOUT=180。已有部署请在原 .env 中添加或调整该项并重建 app 容器；保留原数据目录与其他配置。

验证：81 项后端隔离回归通过，前端生产构建通过。本地浏览器与真实 HTTP 协议替身验证了快速入队、刷新恢复、成功保存、失败原因、503 重试、终态日志及超过 50 条历史任务的详情定位；本地 HTTP 验证取消不新增资料。没有调用真实付费模型，也没有部署用户服务器。

这是服务端与网页修复版本；Android、Windows 原客户端连接同一 HTTPS 服务即可使用。此前的向量来源记录缺失与 OCR 代理超时问题不在本次修复范围。
