# StudyTool 联网服务 0.1.2

修复首次生成向量时遗漏模型来源、导致索引被误锁的问题。新增网页“设置 → 向量索引 → 重建向量索引”，用于恢复已有来源不明或模型已变更的索引。

- 正常向量写入与模式、模型、服务地址记录在同一事务提交；来源不明的旧向量继续保护，不能直接解除锁定。
- 重建须确认当前模型及 API 费用，随后进入后台任务，可查看进度与日志；刷新或离开网页不影响执行，无需长时间等待单个 HTTP 请求。
- 全部有效切片向量生成成功且来源未变化后，原子替换索引并解除锁定。接口失败、取消、资料或配置发生变化时保留旧索引。
- 原文件与已解析正文保留，无需重新 OCR。无可用正文的切片不再保留旧模型向量；仅因向量失败而不可用的教材，成功重建后恢复可读。
- 重建范围为当前登录账号，其他账号资料与索引不受影响。

## 更新

使用 `ghcr.io/sakuralovesmile/studytool:0.1.2` 或本次发布后更新的 `latest`：

```bash
docker compose --env-file .env pull
docker compose --env-file .env up -d
```

页面刷新后进入设置，确认向量模型配置正确，再手动重建索引。此操作调用已配置的向量服务，可能产生费用。更新本身不会自动重建，也不会强制解锁旧索引。

## 验证

80 项隔离后端回归和前端生产构建通过；浏览器验证费用确认、后台排队、刷新恢复、完成日志与解锁、失败提示。使用合成教材与本地 HTTP 向量夹具，未调用真实付费服务或更改生产数据。
