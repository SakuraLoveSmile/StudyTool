# StudyTool 联网服务 0.1.7

章节生成不再要求模型逐字抄写引用原文。此前模型即使成功返回 JSON，也可能因为标点、空格或措辞变化触发 `citation_quote_not_original`，导致整章资料无法保存。

- 将完整章节和本次提供的管理学片段连续分段，每段带有引用编号，正文只发送一份。模型选择支持论述的编号，服务端还原对应的精确原文及位置。
- 编号必须属于本次提供的资料；章节总结与概念仍只能引用所选会计章节。管理学关联保留双方教材依据规则，不补造引用、不模糊匹配或静默丢弃错误引用。
- 兼容模型返回的旧 `chunk_id`、`quote` 格式，并保留原有精确子串校验。新旧字段同时存在且矛盾时拒绝保存，错误日志显示对应字段。
- 不改数据库结构、已保存学习资料或知识库问答协议，不需要重新 OCR，也不增加自动模型调用。引用确实来自教材不代表模型的解释必然正确，仍可通过原文核对。

## 验证

- 109 项相关后端回归通过，包含 14 项新增引用编号测试。
- 本地真实网页配合本机模拟模型、隔离数据库，验证编号生成、精确原文还原、保存后刷新、原文溯源，以及未知编号拒绝且不覆盖已有结果。
- 未调用真实付费模型或 OCR，未修改生产服务器。实际服务商对新引用协议的输出仍需更新后按需验证。

## 更新

```bash
docker compose --env-file .env pull
docker compose --env-file .env up -d
```

镜像为 `ghcr.io/sakuralovesmile/studytool:0.1.7`，发布验证后同步更新 `latest`。更新本身不重新生成资料；更新后按需重新执行失败章节，会使用已配置模型的额度。现有模型、超时和百度 OCR 配置继续适用。
