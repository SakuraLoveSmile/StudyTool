# StudyTool 安卓学习手账 0.1.14

状态：实现中。真机验收及发布尚未完成。

安卓端采用暖纸与墨绿的学习手账界面，手机和平板共享服务端教材、账号和学习记录。需要同时更新联网服务和安卓客户端。

- 手机底部固定“今天 / 教材 / 回忆卡 / 更多”，保留资料、真题分析、讲义、练习、设置、主题和退出入口。
- 平板从840px起使用侧边导航，教材阅读与知识库问答并排；竖屏窄窗口使用紧凑布局。
- 教材支持阅读/问答切换、“问本章”、大字和专注阅读，保留原文、思维导图及来源失效提示。
- 今日学习展示真实学习统计，支持专注背诵，放大揭示、评分及下一张的触控区域。设置和范围可收起；空队列明确提示检查范围及每日新卡上限。
- 原生连接页采用同一配色，服务栏更紧凑；旋转时保留当前WebView，不重新打开学习页面。
- 修复揭示答案返回内容的兼容问题，保留题目和已揭示的答案；重新进入今日学习恢复当前揭示状态，未来题目的答案仍不可见。
- 修复手动评分后意外跳题；评分后保留答案，点击“下一张”继续。补齐轮次完成状态，第三轮明确显示“完成今日学习”。

## 更新

```bash
docker compose --env-file .env pull
docker compose --env-file .env up -d
```

服务镜像：`ghcr.io/sakuralovesmile/studytool:0.1.14`，验证后同步 `latest`。安装本次APK后连接现有HTTPS服务地址。

APK为调试签名候选包，未冒充正式签名。旧候选APK若由其他签名生成，Android会拒绝覆盖安装；不要为更新卸载已有应用。正式持续覆盖升级还需要配置固定发布签名。本次真机验证使用不同应用ID的并存验收包，保留原有应用和数据。
