# 安卓学习手账界面

用户已选择“暖纸＋墨绿”。本次直接实施，沿现有 Vue/FastAPI 业务与 Android WebView 客户端，提供安卓专用界面，不改账号、生成计费、审核发布、复习调度或服务器数据。

## 共享视觉与接入规则

- 安卓客户端 UA 追加 `StudyToolAndroid/0.1.14`，前端通过 `frontend/src/utils/clientPlatform.ts` 的只读布尔值 `isAndroidApp` 识别。`?client=android` 仅用于显式界面预览，不授予权限、不改请求或用户身份。入口在挂载前设置 `html[data-client="android"]`。
- 只在安卓布局中覆盖语义色：暖纸底 `#f6f3ea`、白纸卡片 `#fffdf7`、墨绿重点 `#285c4b`、深墨正文 `#25392f`；深色模式保留，使用深绿灰底和柔和浅绿重点。复用现有 lucide 图标和按钮/输入控件，无新增 UI 库。
- 安卓卡片圆角20px，正文16px/1.8，次要信息12–13px，交互目标至少44px，页面边距手机16px/平板24px。平板阅读正文不无限拉长，约70字符行宽；错误、来源警告、任务状态保持可见。
- 小于840px：手机底部四项导航“今天 / 教材 / 回忆卡 / 更多”，高度约72px并预留安全区；更多包含资料、真题分析、讲义、练习、设置、主题和退出。840px及以上：固定左侧导航栏，主要内容与阅读问答分栏。与Web/Windows共享业务，普通Web布局保持原样。
- 专注背诵入口隐藏非必要统计及设置，保留当前题、揭示、三档自评、下一张、暂停退出和真实进度。不会改变未揭示答案、评分禁用、请求幂等及跨天规则。

## T1 安卓学习导航与全局阅读样式（主 agent）

独占 `App.vue`、`main.ts`、`utils/clientPlatform.ts`、新增 `AndroidStudyShell.vue`、新增 `android.css`。复用任务抽屉、认证、主题与反馈遮罩；安卓登录/改密仍沿现有认证流程。手机底部与平板侧栏互斥，更多菜单可关闭、键盘可操作，路由切换关闭，正文留出导航区域；保留全部既有页面入口。主 agent 同时维护本说明、验证夹具和发布说明。

## T2 教材阅读工作台（reader worker）

独占 `KnowledgeLibraryView.vue`，只读共享组件/API。使用 `isAndroidApp`，保留普通网页原布局。安卓手机：紧凑章节阅读标题，教材与章节选择可收起；章节内容优先，问答通过“问本章”切换面板；总结/导图/背诵/真题 tabs 保持可触达。平板≥840px：教材内容与问答两栏并排，问题输入与答案在右侧，保留资料范围；正文可调字号（标准/大字，局部状态），有专注阅读开关以折叠选择区。未生成、加载、错误、任务和来源过期状态保留；不能伪造笔记或阅读进度，不新增付费调用。

## T3 今天与主动回忆（study worker）

独占 `TodayLearningView.vue` 与 `RecallSession.vue`，只读共享接口。安卓顶部改为“今天，学一点扎实的”学习手账标题，真实统计摘要与开始/继续按钮；教材和回忆卡快捷入口；设置及学习范围可折叠、平板右侧展示。进入专注模式后展示当前回忆题与真实进度，手机揭示/三档评分/下一张有≥48px触控区并靠近内容下方；安卓隐藏键盘提示，平板问题与已揭示答案可分栏。保留原网页模板分支、业务脚本、所有事件/错误/保存反馈和不揭示答案规则。`RecallSession` 新增可选 `focused?: boolean` 只影响呈现。

## T4 原生启动、连接体验与构建（native worker）

独占 `clients/android/**`。连接页沿同一纸色/墨绿风格，手机单列、平板居中限宽及学习方式介绍；更新过时“尚未部署”提示。连接后保留必要服务切换入口，工具条紧凑，UA标记与默认 `/today` 接入；系统栏/键盘/安全区域正确保留，旋转不丢当前学习页面或重放学习请求。不得引入JS原生桥、明文HTTP、证书绕过或扩大权限；保留上传下载/换服清会话规则。版本0.1.14/versionCode14。运行现有单测、lint、assembleDebug，报告签名性质，不冒称正式签名。真实设备/模拟器由主 agent 验证。

T1–T4在上述接口冻结后可并行，同一文件仅一名写入者，子任务不继续派生。各 worker 完成后停止写入并提交改动清单/检查结果；主 agent 集成并实际验证手机390×844、平板1024×768和纵向768×1024的导航、教材/问答、导图、揭示/评分/下一张、空态、登录与普通Web回归。独立 reviewer 检查最终实际改动的状态、来源限制和原生边界。

## 实测发现的必要修复

浏览器完整学习流程发现既有契约缺陷，纳入本次收尾：揭示接口的扁平公开单元被前端当作嵌套尝试而丢失题目/答案；摘要刷新未恢复当前已揭示状态。修复只对当前已揭示尝试恢复答案，队列及未来题继续隐藏，评分幂等身份保留。另核对手动评分后的“下一张”与本轮完成推进，保持原有每日量、轮次和跨天规则。
